# Battlefield materials

These six textures are original procedural PBR maps generated by
`python3 tools/build-godot-battlefield-textures.py` (Pillow and NumPy).
The fixed seed, file sizes, and SHA-256 values are in `manifest.json`.
They contain worn earth/stone, fine mineral grain, fractures, impact stains,
and a subdued teal riverbed. Character models and their original texture
atlases are not modified.

Use the board maps once across a **24.65 × 27.25** world-unit `PlaneMesh`.
The texture centre is the board centre. The river crosses X from −10.5 to
+10.5, centred at Z = 0; the irregular banks are around Z = ±1.0.
Grid lines and river lettering remain scene geometry and are not baked in.

The 512² ground maps tile; approximately one repeat per 12 world units gives
the same grain scale as the board. The board maps are 1024². Every map has
explicit mipmap import settings for deterministic headless web exports.

Material setup:

- Albedo maps use sRGB; start with an untinted white albedo multiplier.
- Normal maps use the OpenGL (+Y) convention. Suggested normal strengths are
  0.65 on the board and 0.7 on the ground.
- Roughness maps are scalar linear data in the red channel; set material
  roughness to 1.0 and metallic to 0.0.
- Use linear filtering with mipmaps. Enable repeat for the ground.

The generator supplies import configuration for lossless textures. These
are modest-sized maps; there is no dependence on external texture hosting,
AI image services, or browser-generated raster canvases.
